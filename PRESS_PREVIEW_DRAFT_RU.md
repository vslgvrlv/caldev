# PaintBall Team Hub — Press Preview Draft

## 1) Кратко о проекте
PaintBall Team Hub — Telegram-first платформа для управления пейнтбольной командой: календарь событий, RSVP, состав, финансы, напоминания и командные процессы в одном интерфейсе.

Основная идея: убрать хаос из чатов и дать капитану/тренеру прозрачную операционку команды, а игрокам — простую точку входа через Telegram.

---

## 2) Что было сделано (подтверждено кодом)

### 2.1 Стабилизация фронтенда и прод-структуры
- Убраны нестабильные зависимости в `index.html` (включая `importmap`) и переведена загрузка vendor-скриптов через backend endpoint `/api/vendor/*`.
- Добавлены SEO/OG мета-теги и canonical для домена `pbthub.ru`.
- Добавлен `vite.config.ts` с `allowedHosts` для `pbthub.ru` и `www.pbthub.ru`.
- Добавлен `Dockerfile` фронтенда + `.dockerignore`.
- Обновлён `docker-compose.yml` для корректного frontend context.

### 2.2 Лендинг и маркетинговая оболочка
- Hero-блок приведён к бренд-стилю: выраженный заголовок с акцентом `Побеждай на поле.`, усиленный фон, glow-эффекты.
- В бейдж `Открытый бета-тест` добавлена микро-анимация.
- Полированы CTA-кнопки, hover/active состояния и визуальная иерархия.
- Переработаны секции `Как это работает` и `Тарифы` (карточки, контраст, акценты).

### 2.3 Пользовательские публичные страницы
- Добавлены отдельные страницы:
  - `/privacy`
  - `/terms`
  - `/support`
- Footer на лендинге теперь ведёт на реальные страницы вместо заглушек.

### 2.4 Работа с уведомлениями
- В backend реализована отправка event reminder и debt reminder через Telegram Bot API.
- Добавлена классификация типовых Telegram ошибок:
  - `chat not found`
  - `bot was blocked by the user`
  - `user is deactivated`
- Это позволяет видеть не просто факт ошибки, а причину недоставки.

### 2.5 Техническая проверка выкладки
- Подготовлен smoke-check скрипт (`scripts/smoke-check.sh`) для проверки:
  - `/api/health`
  - auth state
  - доступности frontend
  - доступности Telegram endpoint’ов
  - загрузки собранного JS bundle

## 3) Что это даёт пользователю
- Быстрый вход через Telegram без отдельной регистрации.
- Единая точка управления командой: события, явка, финансы, напоминания.
- Более предсказуемая доставка уведомлений и прозрачная диагностика ошибок.
- Публичный сайт готов для продвижения: домен, SEO-база, понятный лендинг.
